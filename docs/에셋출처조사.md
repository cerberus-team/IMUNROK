# 외부 에셋 출처 조사 — 2026-08-26

> **조사만 한 문서다. 아무것도 지우거나 옮기지 않았다.**
> 합치기(머지) 전에 팀원과 GUID 가 어긋날 수 있는 지점을 가려내는 것이 목적이다.

## 어떻게 판별했는가

1. **에셋 스토어 캐시** `%APPDATA%\Unity\Asset Store-5.x\` 를 훑어 `.unitypackage` 16개를 뽑았다
   (게시자 폴더 10곳 · 합계 약 18.6 GB).
2. 캐시 목록과 `Assets/` 최상위 폴더 33개를 대조했다. **폴더명이 팩 이름과 다른 경우가 많아**
   폴더 안의 파일 구조·README·머티리얼 이름으로 짝을 지었다.
3. 캐시에 없는 폴더는 내부 구조로 출처를 판정했다
   (`source/` + `textures/` 짝 = Sketchfab 내려받기, README·FBX 단일 = 팀원 제작 등).
4. **실사용 여부**는 이미 뽑아 둔 `docs/UnusedAssets_2026-08-26.md` 의 구역별 합계를 썼다.
   빌드 설정에 등록된 씬 12개 + `Resources` + `ProjectSettings` 를 뿌리로 삼은 수치다.

⚠️ 「쓰는 양」은 **폴더 총량 − 미참조량**이다. 데모 씬만 쓰는 파일은 미참조로 세었으므로,
   이 값은 「우리 12개 빌드 씬이 실제로 물고 있는 양」에 해당한다.

## 5. 합치기 전 반드시 처리할 것

1. **`Assets/Unity_Final_Characters_Textured/` 를 `.gitignore` 에 넣을지 결정한다.**
   지금 상태로 `git add .` 하면 115 MB 가 LFS 로 올라간다.
   씬 6개가 물고 있으므로 **`.meta` 는 반드시 커밋**해야 한다 (글꼴과 같은 규약).
2. **`Assets/_Recovery/` 를 `.gitignore` 에 넣거나 지운다.** 지금 커밋 사각지대다.
3. **`Assets/Shaders/Uber Stylized Water` 의 배포 방법을 정한다.**
   GitHub 각자 내려받기는 안 된다 — 물 재질 두 개가 GUID 로 물려 있다.
4. `woljeonggyo` · `Joseon Library` 도 같은 문제다. **각자 Sketchfab 내려받기 금지**,
   임포트된 폴더째 전달로 못 박아 두어야 한다.
5. CLAUDE.md 의 「외부 에셋 취급 규칙」에 위 4건을 명시한다.
