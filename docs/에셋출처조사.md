## 조사 방법

1. 에셋 스토어 캐시 `%APPDATA%\Unity\Asset Store-5.x\` 의 `.unitypackage` 35개 목록 확보 (퍼블리셔 24곳)
2. 캐시 목록과 `Assets/` 하위 폴더를 대조 — 폴더명이 팩 이름과 다른 경우가 많아 팩 내부 문서(`Readme.txt`, `*.pdf`), 폴더 구조, 파일명 접두사로 판별
3. 실사용 여부는 프로젝트 씬 6종(`IntroScene` / `HubScene` / `InterrogationScene` / `EndingScene` / `Seocheon` / `Seocheon_Flowerfield`)의 의존성 합집합(1822개)으로 판정
4. FBX 파일은 바이너리 헤더의 `Creator` 문자열을 읽어 원본 제작 도구를 직접 확인

### 판정의 한계

- **씬 참조 기준**입니다. `Resources.Load()` 런타임 로드, Addressables, 스크립트 내 하드코딩 경로는 잡히지 않습니다.
- 따라서 사용률 0%라도 **`Resources/`, `Plugins/`, `Oculus/`, `TextMesh Pro/`는 Unity 특수 폴더라 삭제 대상이 아닙니다.**

## 2. 위험도 판정

### 🟢 안전 — 스토어 팩 (26개 폴더, 약 6.7 GB)

에셋 스토어 팩은 **GUID가 팩 자체에 박혀 있습니다.** 팀원이 같은 팩·같은 버전을 스토어에서 받으면 GUID가 자동으로 일치합니다.

> **따라서 이 팩들은 unitypackage에 넣지 말고, 팀원이 스토어에서 직접 받는 것이 정석입니다.**
> 패키지에 넣으면 용량만 늘고 오히려 버전 어긋남 위험이 생깁니다.

단, 팩 **버전이 다르면** GUID가 달라질 수 있습니다. GUID 지문 대조 스크립트(`_TeamHandoff/README.md` 4항)로 확인이 필요합니다.

### 🔴 위험 — 스토어에서 구할 수 없음 (4개 폴더, 약 1.67 GB / 사용분 746 MB)

| 폴더 | 근거 |
