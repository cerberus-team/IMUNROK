⑤ ★지형 디테일 빌보드의 색 한계 — 이번 라운드의 핵심 발견

  빌보드에 healthyColor 를 흰색(1,1,1)으로 두고 찍은 ★단위 응답
     화면 표시 (0.288, 0.350, 0.407)  = linear (0.0674, 0.1005, 0.1378)
     이때 휘도비 1.55 (색은 없음)

  ★healthyColor 는 [0, 1] 로 ★클램프된다 (실측 확인: 틴트 R 을 1.23 / 1.66 / 3.50 으로
    올려도 화면 R 이 전혀 변하지 않았다).
  ★단위 응답의 B 가 R 의 ★2.04 배다. 이유는 조명 (0.72,0.86,0.92) 이 푸르고
    해가 고도 10도 역광이라 수직 빌보드가 확산광을 거의 못 받기 때문이다.
  -> 화면_linear = 단위응답 x 틴트,  틴트 <= 1 이므로 ★R 우세(마젠타/분홍)를 만들려면
     G 와 B 를 크게 깎아야 하고 그만큼 휘도가 떨어진다.

  Purple 의 경우 (수치 탐색 결과)
     색상오차 <= 25도 · 채도 >= 0.18  를 만족하는 ★최대 휘도비 = 0.82
     휘도비 >= 1.30 을 만족하는       ★최소 색상오차 = 100도
     ★두 조건은 이 조명에서 ★동시에 만족될 수 없다.

  -> 이번 라운드는 ★색(색상각)을 택했다. Phase 1 의 A 가 실패한 원인이
     "어둡다" 가 아니라 "★무채색이다" 였기 때문이다.
