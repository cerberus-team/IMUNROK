[3] 부채꼴 5구역

  h(r,theta) = A_eff(r,theta) * 0.5 * (1 + cos(pi * r / R(theta)))   r >= R 이면 0
  -> 링 경계에서 높이도 기울기도 0 이므로 페이드가 필요 없다

  구역 (중심 방위 / 진폭)
     Z0  335.4 deg / 3.0 m   ★스폰이 여기 (스폰 방위 335.4 = 구역 한가운데)
     Z1   47.4 deg / 7.0 m
     Z2  119.4 deg / 12.0 m  ★가장 높음 · P1 화면 왼쪽
     Z3  191.4 deg / 4.5 m   ★P1 화면 오른쪽
     Z4  263.4 deg / 9.0 m   버드나무 (412,688) 가 여기
     폭 72 deg · 경계는 중심 +-36 deg
     경계 5곳 : 11.4 (Z0/Z1) · 83.4 (Z1/Z2) · 155.4 (Z2/Z3) · 227.4 (Z3/Z4) · 299.4 (Z4/Z0)
     ★진폭 평균 = 7.1 m  (중심 수렴값)

  ★경계 블렌드 — 각도가 아니라 ★호 길이로
     phi(r) = degrees( W_arc / r ) ,  W_arc = 20.0 m
     -> r 96 에서 +-11.9 deg · r 50 에서 +-22.9 deg  (지시서 검산값과 일치)
     -> 전이 구간의 ★호 길이가 2*W_arc = 40 m 로 반경에 무관하게 일정하다
        (각도 고정 폭이면 중심 근처에서 호가 짧아져 절벽이 된다:
         r=25 에 +-12 deg 면 호 10.5 m 에 7.5 m 낙차 = 36 deg)

     A_eff(r,theta) = sum_k A_k * w_k / sum_k w_k
     w_k = g( ang(theta - (theta_k - 36)) ) * g( ang((theta_k + 36) - theta) )
     g(x) = GLSL smoothstep(-phi, +phi, x)  =  u=clamp((x+phi)/(2phi),0,1); u*u*(3-2u)
     ★ang() 는 -180~+180 로 감는다 -> 방위 함수가 ★360 deg 주기가 되어 0/360 이음매가 없다
     ★Mathf.SmoothStep(from,to,t) 와 인자 의미가 다르므로 직접 구현한다

  ★★지시서 §4-3 의 "phi = min(30 deg, W_arc/r)" 중 ★30도 클램프는 적용하지 않았다
     이유 : 클램프를 걸면 §4-5 의 ★"중심 상승 7.1 m" 와 ★"중심 불연속 <=0.15 m" 가
            ★원리적으로 불가능해진다. 계산은 이렇다.
            phi = 30, 반각 36 이면 구역 중심(d=0)에서
               w_own = g(+36)*g(+36),  u = (36+30)/60 = 1.1 -> clamp 1 -> s = 1
               w_이웃(d=72) = g(108)*g(-36),  u = (-36+30)/60 = -0.1 -> 0  -> w = 0
            즉 r 을 아무리 줄여도 구역 중심의 A_eff 가 ★자기 진폭 그대로다.
            r->0 에서 12.0 / 3.0 / 9.0 ... 이 방향마다 남으므로 중심이 ★불연속이 된다.
            (중심 텍셀은 방위 202.2 deg 에 떨어져 A_eff 약 4.7 -> 7.1+-0.15 판정 실패)
     클램프를 빼면 phi 가 r->0 에서 발산하고 다섯 구역 가중치가 모두 같아져
        A_eff -> (12+7+4.5+3+9)/5 = ★7.1 로 정확히 수렴한다. 검산 :
        r=2 (phi 573) A_eff(Z2축) 7.18 · r=10 (phi 114.6) 8.82 · r=20 (phi 57.3) 10.87
        r=25 11.60 · r=35 이상 12.00
     ★지시서의 서술 "중심 부근은 5구역이 사실상 하나로 합쳐지고 바깥으로 갈수록 갈라진다"
       도 클램프를 뺀 쪽이 정확히 그 거동이다. 검산값 (r 96 / r 50) 은 그대로 재현된다.
     ★이것은 진폭을 바꾼 것이 아니다. 진폭 5개는 지시서 값 그대로다.
