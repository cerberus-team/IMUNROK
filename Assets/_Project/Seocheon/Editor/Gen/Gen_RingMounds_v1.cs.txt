[4] 다중 동산

  4-1 밑동산
     중심 링 중심 · 반경 R(theta) · ★A_base = 5.0 m (고정. 배율을 걸지 않는다)
     h_base(r) = A_base * 0.5 * (1 + cos(pi * r / R(theta)))   r >= R 이면 0
     -> 링 경계에서 높이도 기울기도 0 이므로 페이드가 필요 없다
     -> 최대 기울기 = A_base*pi/(2R) = 5*pi/190 = 0.0827 -> ★4.73도

  4-2 봉우리 7개
     h_i = A_i * 0.5 * (1 + cos(pi * d_i / R_i))   d_i >= R_i 이면 0
     R_i = 18~32 m 무작위 · A_i = 2.5~5.0 m 무작위
     ★노이즈 임계값 금지 (ridged 잡음 + 임계 = 닫힌 셀 경계 = 퍼즐조각 윤곽)
     ★명시적 코사인 봉우리의 합으로만 만든다

     배치 제약 (포아송 디스크)
       (a) 봉우리 중심 간 ★최소 D m 이격        D 는 34 에서 시작
       (b) ★링 경계에서 최소 18 m 안쪽
       (c) ★길 중심선에서 최소 16 m
       (d) ★버드나무 (412, 688) 반경 8 m 안에 정점 금지
       (e) ★추가 제약 — 봉우리가 링 안에 ★완전히 들어올 것 (r_i <= R(theta_i) - R_i)
           지시서의 (b) 는 18 m 인데 R_i 가 최대 32 m 라 18 m 만으로는 치맛자락이
           링 밖으로 새어 나간다. 그러면 "링 바깥 변화 0.00 m" 를 위반한다.
           -> 여유 = max(18, R_i) 로 ★조인다. (b) 를 완화한 것이 아니라 강화한 것이다.

  4-3 ★경사 클램프 (겹치면 기울기가 더해진다)
     최종 = H_flat + h_base + (1-w) * s * Sigma h_i
     ★링 안쪽 최대 경사가 11.0~12.0 도에 들어오는 배율 s 를 ★이분탐색으로 찾는다
     ★A_base 5.0 은 고정. 배율은 ★봉우리에만 건다
     ★봉우리를 개별로 골라 낮추지 않는다
     ★s 탐색은 ★길 마스크를 포함한 최종 지형에서 한다. 길 페이드가 만드는 경사도
       s 에 단조 의존하므로 이분탐색이 성립한다.

  4-4 ★안부 (이 라운드의 핵심 지표)
     인접 = 중심 간 거리 <= 65 m 인 모든 쌍
     안부 = 두 정점을 잇는 선분 위 ★최종 지형 고도의 최소값
     판정 = 두 정점 평균 고도보다 ★1.5 m 이상 낮을 것 · 미달 쌍 0

     ★12도 상한과 1.5 m 안부는 서로 밀어낸다. 계산해 두면
        최대 경사 조건 : A_eff,i * pi / (2 R_i) + 0.0827 <= tan(12도)=0.2126
                        -> A_eff,i <= 0.0827 * R_i
        안부 조건(등가 봉우리) : depth = A_eff * |cos(pi*d/(2R))| >= 1.5
        -> R_i 가 18 이면 A_eff 상한이 1.49 라 ★1.5 m 안부가 원리적으로 불가능하다
        -> R_i 20~28 · d/R_i >= 1.5 부근이 유일한 통과 구간이다
     ★그래서 진폭을 키우지 않고 ★배치를 다시 뽑는다 (지시서 §5-4 의 지침 그대로).
       D 를 34,36,38,40,42 로 올리고 각 D 에서 시드를 바꿔 가며 ★기각 표집한다.
       통과하는 (D, 시드) 를 만나면 즉시 채택하고 ★그 값을 보고한다.
     ★통과 조합이 없으면 최선의 조합을 적용하고 ★실패라고 쓴다.

  ★난수는 ★결정론적 LCG (UnityEngine.Random 금지)
     unchecked { uint s=(uint)seed*1664525u+1013904223u;
       s^=s>>15; s*=2246822519u; s^=s>>13; s*=3266489917u; s^=s>>16;
       return (s & 0xFFFFFFu)/16777216.0; }
