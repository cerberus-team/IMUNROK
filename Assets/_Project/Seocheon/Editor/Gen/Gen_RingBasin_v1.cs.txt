[3] 형태 — 세 항의 합

  h(r,theta) = W_eff(r,theta) - B(r)      평탄화 결과 위에 더한다

  3-1 중심 분지 B(r)          r0=16.0 · r_b=34.0 · D=2.0
      B = D                                              (r <= r0)   ★평탄한 바닥 원
        = D*0.5*(1+cos(pi*(r-r0)/(r_b-r0)))              (r0<r<r_b)
        = 0                                              (r >= r_b)

  3-2 구역 융기 W(r,theta)
      u = clamp((r-r0)/(R(theta)-r0), 0, 1)
      W = A_eff(r,theta) * 0.5 * (1 - cos(2*pi*u))
      -> u=0 (분지 가장자리) 0 · u=0.5 (중심에서 약 56 m) ★최대 A · u=1 (링 경계) 0
      ★마루가 중심이 아니라 ★중간 반경에 고리로 생긴다. 이것이 S20 과의 결정적 차이다.
      최대 기울기 = A*pi/(R-r0)  ~ A*pi/80

      구역 (중심 방위 / 진폭)
         Z0 335.4 / 4.0   ★스폰이 여기 (가장 낮게 — 너머가 보여야 한다)
         Z1  47.4 / 7.5
         Z2 119.4 / 9.0   ★가장 높음 · P1 화면 왼쪽
         Z3 191.4 / 5.5   P1 화면 오른쪽
         Z4 263.4 / 8.0   버드나무 (412,688)
      폭 72도 · 경계 5곳 : 11.4 / 83.4 / 155.4 / 227.4 / 299.4
      ★P1 시선축 155.4 도가 Z2-Z3 경계(골) 위에 놓인다

  3-3 구역 경계 블렌드 — ★호 길이로
      phi(r) = min( 30 deg , degrees(W_arc / r) ) ,  W_arc = 20.0
      A_eff = sum(A_k * w_k) / sum(w_k)
      w_k = 1 - GLSL_smoothstep( 36 - phi, 36 + phi, d_k )
      d_k = ★감긴 각거리(theta, ZC[k]) in [0,180]  -> ★구조적으로 360도 주기
      - 경계(d=36)에서 w 가 0.5/0.5 -> 두 진폭의 평균
      - 경계에서 +-phi 에서 블렌드가 정확히 끝난다 (지시서 정의와 일치)
      ★S20 에서는 이 30도 클램프가 "중심 수렴 7.1" 을 불가능하게 만들어 뺐지만,
        ★이번에는 클램프를 ★그대로 적용한다. W 가 분지(u=0)에서 0 이라
        중심의 A_eff 값이 지형에 전혀 나타나지 않기 때문이다. 중심 불연속 문제가 없다.
      ★Mathf.SmoothStep(from,to,t) 와 인자 의미가 다르므로 직접 구현한다

  3-4 골 5갈래 — ★W 에 곱하는 감쇠로만
      d = 가장 가까운 구역 경계까지의 ★호 길이 = r * (각거리 rad)
      t = 1 - GLSL_smoothstep(0, 9.0, d)
      W_eff = W * (1 - 0.55 * t)
      -> 경계 위에서 융기가 45 % 로 눌린다
      -> 분지(u=0)와 링 경계(u=1)에서 W=0 이므로 골도 자연히 사라진다
      ★음수 항으로 파지 않는다. 음수면 분지 안과 링 밖까지 홈이 뚫린다.

[4] 경사 클램프

  ★h 는 W 항이 A 에 선형이고 B 항은 A 와 무관하다
     -> 기울기 = G_flat + G_B + s * G_W   (G_B 는 s 에 무관)
     -> G0 = G_flat + G_B , G1 = G_W 로 두면 |G0 + s*G1| = tan(21) 의 양의 근을
        텍셀마다 풀고 최소값을 취하면 최대 경사가 정확히 21 도가 되는 s 를 한 번에 얻는다
        (이분탐색 불필요. S19/S20 에서 쓴 방법과 같다)
  ★링 안쪽 최대 경사가 22 도 이하이면 s = 1 로 두고 실측값을 보고한다
  ★배율은 ★구역 진폭 A 에만 건다. ★D=2.0 · 골 계수 0.55 · W_arc=20 · 골 폭 9.0 은 불변

  ★예상되는 긴장 (실행 전에 적어 둔다)
     골이 만드는 ★둘레방향 기울기 = 0.55 * W * max|smoothstep'| = 0.55 * W * 1.5/9
                                   = 0.0917 * W
     마루(u=0.5)에서 W = A 이므로 A=9 이면 0.825 -> ★39.5 도.
     22 도 상한이 이 항을 누르면 s 가 0.45 부근까지 내려가고,
     골 깊이도 같은 비율로 줄어 ★"골 최심 2.0 m" 를 못 맞출 수 있다.
     ★그래도 지시서 값을 먼저 실행해 결과를 내고 보고한다. 값을 미리 바꾸지 않는다.
