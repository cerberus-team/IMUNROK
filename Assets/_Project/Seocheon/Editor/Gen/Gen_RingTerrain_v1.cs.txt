[1] 링 영역 정의

  링 중심   (463, 678)
  방위 반경  E 96.3 · W 89.9 · S 107.0 · N 91.2      (1부 마을 실측치)
     ★개천 링 ★메시는 의뢰인이 제거했다. 이 라운드에서는 링을
       ★영역 정의의 기준으로만 쓴다. 링 오브젝트를 다시 만들지 않는다.

  방위별 반경의 각도 보간 = ★타원 사분면 혼합
     방향 단위벡터 (ux, uz) = ((wx-463)/r, (wz-678)/r)
     Rx = ux > 0 ? E : W
     Rz = uz > 0 ? N : S
     R(theta) = 1 / sqrt( (ux/Rx)^2 + (uz/Rz)^2 )
     -> 네 방위에서 정확히 E/W/S/N 값을 지나고 그 사이는 매끄럽다

[2] 단계 2 — 평탄화 (S11 에서 검증된 방식)

  H_flat = 원지형을 ★sigma 12 m 가우시안으로 평활한 것
     ★분리 가능한 1D 2회 (x -> z). 2D 커널 직접 루프는 타임아웃.
     sigma 12 m = 6.144 텍셀 · 커널 반경 3sigma -> KR 19 텍셀

  적용 = 링 안쪽 전체, 링 경계에서 ★바깥으로 20 m 페이드
     d = r - R(theta)                     링 안이면 음수
     u = clamp(d / 20, 0, 1)
     s = u*u*(3-2*u)                      ★GLSL smoothstep 직접 구현
                                          (Mathf.SmoothStep 은 인자 의미가 다름)
     H = H_flat * (1-s) + H_orig * s

  판정
     ★고도 범위 유지율 70~90 %   (100% = 아무것도 안 함 / 40% = 접시)
     3x3 국소 표준편차 · 경사 <=7% 비율 · ★최대 경사 — 전후 병기
     ★페이드가 추가한 단차 <= 0.35 m   (원지형 자체 단차와 함께 보고)
     ★링 바깥 산자락 변화 <= 0.05 m

  ★"경계 단차 <=0.25 m" 같은 기준을 새로 만들지 않는다.
    원지형이 이미 0.851 m 인 자리가 있었다. 기준은 ★원지형에서도 성립하는지
    먼저 확인하고 쓴다.

[3] 단계 3 — 코사인 동산

  중심   링 중심 (463, 678)
  반경   R(theta)  (위 [1] 과 동일)
  정점   ★A = 8.0 m
  프로파일  h(r) = A * 0.5 * (1 + cos(pi * r / R(theta)))     r < R
            h = 0                                            r >= R
  적용   ★평탄화 결과 위에 ★더하기

  ★왜 8.0 m 인가
     코사인 돔의 최대 기울기 = A * pi / (2R)
     A 8.0 · R 95  ->  최대 ★7.5도 · 평균 4~5도
     걸어 오르는 느낌은 나되 "산"이 되지 않는 구간이다.
     의뢰인이 손으로 만든 13.4 m 는 최대 12.7도로 산길에 가까웠다.
  ★A 를 임의로 바꾸지 않는다. 렌더가 명백히 나쁘면 8.0 결과를 먼저 내고 제안한다.

  ★링 경계에서 높이도 기울기도 0 이므로 ★페이드가 필요 없다
     h(R) = A*0.5*(1+cos(pi)) = 0
     h'(r) = -A*pi/(2R)*sin(pi r/R)  ->  r=R 에서 sin(pi)=0

  판정
     링 중심 상승 +8.00 m (+-0.02) · 링 경계 상승 0.00 m (+-0.01)
     ★최대 경사 <= 12도 · 경사 <=12도 비율 100% 목표
     >5.0 m 단차 텍셀 0 · ★링 바깥 변화 0.00 m
