[0] 3단계가 실패한 이유와 이번의 차이

  실패  고도 16~40 m = 블렌드 / 40 m 이상만 암반
        -> 눈높이 화면을 채우는 것이 바로 16~40 m ★산자락인데 거기에 꽃을 칠했고
           정작 평지는 흙으로 남겼다
  이번  ★평지 = 들풀 · 산 = 암반+흙 · ★밭 자리 = 맨흙
        밭을 흙으로 남기는 것이 핵심 — 갈아엎은 밭은 흙바닥이 맞고,
        전부 풀로 덮으면 ★의뢰인이 손으로 칠할 때 밭 자리가 안 보인다

  ★실측한 지형 분포 (판정 표본이 충분한지 먼저 확인했다)
     고도 4.3 ~ 98.2 m    10~20 m 가 70.7%
     경사 최대 85.7도     0~10도가 66.6%
     평지(고도<=14 & 경사<=12) ★170,791 텍셀
     산  (고도>=25)            ★60,820 텍셀
     경사>=28도                ★51,464 텍셀

[3] 도색 규칙 — ★고도·경사 연속 함수로만

  ★높이맵 불가침. 반경·방위로 자르지 않는다 (밭 마스크만 예외)
  ★alphamap 1024^2, 지형 size 1000 -> 알파맵 텍셀 0.9766 m

  3-1 산 / 평지
     a = smoothstep(13, 21, h)        고도 (GLSL 의미)
     b = smoothstep(13, 23, s)        경사
     wMountain = saturate(max(a, b))
     ★wMountain 을 sigma = 4 텍셀 가우시안으로 ★공간 평활
        (3단계에서 경사 smoothstep 이 절벽에서 1텍셀 안에 통과해 하드 경계를 만들었다)
     wFlat = 1 - wMountain
     wFlat *= (1 + 0.15 * noiseLF)            파장 60~120 m
     L2 = wFlat * 0.72 * (1 - wField)
     L3 = wMountain * 0.55
     rest = 1 - L2 - L3  ->  L0/L1 로 배분
        비율에도 저주파 노이즈(파장 25~50 m, +-0.20) — 흙 타일 반복감 완화
     마지막에 4채널 합 1.0 정규화

     ★L3 를 0.55 로 두는 이유 — 암반이 산을 다 덮으면 회청색 덩어리가 되어
       존재감이 커진다. 45% 를 흙으로 남겨 산이 배경으로 물러나게 한다

  3-2 ★밭 마스크 (흙으로 남길 곳)
     8구역 확장 사각형(바깥 2 m) + 구역 사이 길, 경계에서 ★4 m 페이드
     좌표 = Phase 1 확정 (Gen_DetailFlowers_v2.cs.txt)
       CX {434.000,446.990,438.842,449.801,460.399,438.114,450.737,462.507}
       CZ {699.600,698.638,678.888,677.770,677.291,666.050,667.264,667.737}
       RT {  8, 172, 145, 112,  78,  45,  20, 165}   SA {11,11,9,9,9,9,9,9}  SB {7 x8}
       길쌍 PA {0,2,3,5,6,2,3,4}  PB {1,3,4,6,7,5,6,7}   반폭 1.5 m
     wField = 1 - smoothstep(0, 4, dFarm)
     ★밭 안에서 L2 = 0, L3 = 0 -> L0/L1 흙만
     ★밭 마스크는 알파맵에만 쓰는 예외다
