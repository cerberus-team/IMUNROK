// ----------------------------------------------------------------------------
//  ★3. 구역 도형 — ★사각형을 버린다 (판때기의 원인)
//
//   구역 b 의 로컬축   th = RT[b];  ax=(cos th, -sin th);  bx=(sin th, cos th)
//   로컬좌표 la (길이축, SA), lb (폭축, SB)
//
//   ① 기저 도형 = ★초타원(superellipse) n = 2.5   (타원과 사각형 사이)
//        방향 각 ph = atan2(lb, la)
//        Rbase(ph) = 1 / ( (|cos ph|/(SA/2+G))^n + (|sin ph|/(SB/2+G))^n )^(1/n)
//        ★G = 1.20 m 확장. 확장분은 뒤에서 길로 다시 깎는다.
//          -> 구역이 섬처럼 떨어져 있지 않고 ★밭 하나에 길이 난 그림이 된다
//
//   ② ★윤곽 노이즈 (지시서 ①: 파장 3~8 m · 진폭 0.8~1.5 m)
//        Rn(ph) = A1*sin(k1*ph + p1) + A2*sin(k2*ph + p2)
//        k1 = 4 (둘레 ~28 m 기준 파장 ~7.0 m)   A1 = 0.75
//        k2 = 7 (파장 ~4.0 m)                   A2 = 0.45
//        합 진폭 최대 1.20 m -> 0.8~1.5 안
//        p1,p2 는 구역마다 다른 고정 위상 (LCG)
//        ★구역 회전 RT 가 8/172/145/112/78/45/20/165 로 이미 축정렬을 깨뜨린다.
//          여기에 노이즈가 더해져 0/90도 직선이 남지 않는다 -> §3② 히스토그램으로 검증
//
//   ③ R(ph) = Rbase(ph) + Rn(ph)
//      점의 경계까지 거리(근사)  d = R(ph) - sqrt(la^2 + lb^2)
//
//   ④ ★경계 페이드 (지시서 ②: 1.5~2.5 m 폭에 걸쳐 255 -> 0)
//        cov_b = clamp(d / W, 0, 1),  ★W = 2.25 m
//        선형이므로 90% -> 10% 폭 = 0.8 * W = ★1.80 m  (1.5~2.5 안)
//
//   ⑤ 여러 구역이 겹치면  cov = max(cov_b),  지배구역 bd = argmax
//
// ----------------------------------------------------------------------------
//  ★4. 밀도 변조 (지시서 ③: 파장 4~9 m · ±15%, ±20% 초과 금지)
//
//   n(x,z) = 0.5*sin(2pi*( x*0.160 + z*0.090) + q1)
//          + 0.5*sin(2pi*(-x*0.070 + z*0.140) + q2)
//   파장 = 1/sqrt(0.160^2+0.090^2) = 5.44 m,  1/sqrt(0.070^2+0.140^2) = 6.39 m  -> 4~9 안
//   mod = 1 + 0.15 * n        (n in [-1,1] -> ±15%)
//   ★변동계수 CV 목표 0.08~0.20 — 페이드 구간을 뺀 ★내부 셀에서만 측정한다
//
// ----------------------------------------------------------------------------
//  ★5. 색 혼합 (지시서 ④: 지배 88% + 보조 12%, 경계 2 m 안에서 보조 최대 30%)
//
//   보조색 = ★인접 구역의 색 (아래 인접표)
//     B01<->B02   B03<->B04<->B05   B06<->B07<->B08   B03<->B06  B04<->B07  B05<->B08
//     근접군 B01/B02 는 서로가 유일한 인접 -> B01 보조=Yellow, B02 보조=Purple
//
//   e = clamp((2.0 - d) / 2.0, 0, 1)          경계 2 m 안에서 1 로 간다
//   wsec = 0.12 + 0.18 * e                     0.12 ~ ★0.30
//   layer[BB(지배색)] += V * (1 - wsec)
//   layer[BB(보조색)] += V * wsec
//   V = round(255 * cov * mod)
//
// ----------------------------------------------------------------------------
//  ★6. 길 (지시서 2-6)
//
//   경로쌍 8개 (Gen_Flowerblocks_v1 의 인접 구조를 그대로 쓴다)
//     01-02  03-04  04-05  06-07  07-08  03-06  04-07  05-08
//   중심선 = 두 구역 중심을 잇는 선분을 ★수직으로 sin 오프셋해 휜다
//     off(t) = 0.55 * sin(pi * t) * s      s = ±1 (구간마다)   ★직선 금지
//   폭     w(t) = wB + 0.22 * sin(2pi * 1.5 t + ph)   -> 구간마다 다른 wB
//     wB  01-02 1.25 · 03-04 1.70 · 04-05 1.35 · 06-07 1.55
//         07-08 1.30 · 03-06 1.75 · 04-07 1.45 · 05-08 1.60      (전부 1.2~1.8)
//   길 마스크  pm = clamp((dist - w/2) / 0.35, 0, 1)   ★0.35 m 짧은 페이드
//   최종 cov *= pm
//
//   ★근접군(B01·B02) - 원경군(B03~B08) 사이 11.1~11.9 m 는 ★그대로 빈 땅으로 둔다
//     Z 688~693 에 경사 11~17도 능선이 가로지른다. 지형이 강제한 폭이다.
//     길보다 넓은 맨땅이므로 통행은 오히려 자유롭다 -> 고립 판정은 ★피복 0 영역의
//     연결성분으로 계산해 확인한다
