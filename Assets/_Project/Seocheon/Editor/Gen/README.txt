서천 꽃밭 — 절차적 에셋 생성 스크립트 보존 폴더
================================================================

★규칙 (2단계 v17 §7 에서 신설)
  절차적으로 에셋(큐브맵·텍스처·메시)을 생성하는 코드는 ★실행 전에 반드시
  이 폴더에 파일로 저장한다. 이름은 Gen_<대상>_<버전>.cs.txt.
  파라미터·시드·상수를 포함한 실행본 그대로 남길 것.

  확장자를 .cs.txt 로 두는 이유: 유니티가 컴파일하지 않는다.
  UnityMCP execute_code 에 붙여넣어 실행하는 원문 기록이다.

★왜 생겼나
  CM_Flowerfield_Sky_v11 의 생성 스크립트가 인라인 execute_code 로만 실행됐고
  history 가 비워지면서 영구 유실됐다. 그 결과 다음이 복구 불가가 됐다.
    - 구름 알파 필드           -> "오로라가 구름에 최대 50% 가려짐" 사양 재현 불가 (이탈 확정)
    - 구름 커버리지 0.519 / 불투명도 0.331 / 주파수비 7.08
    - 배경 별 최대 가산 0.130
    - 하늘 고도대 그라데이션 원식 / 난수 시드
  이후 모든 큐브맵 작업은 v11 텍셀을 실측해 차분 편집하는 방식으로만 가능하다.

파일
================================================================

Gen_SkyCubemap_v13.cs.txt
    2단계 v17 본체. 큐브맵 v13 을 만든다.
      RGB = base ( = v11 - A_v11, 오로라가 제거된 하늘 )
      A   = 오로라 강도 마스크 (색 없음, +-0.5 LSB 삼각 디더)

    ★PASS 1 이 곧 "A_v11 추출 코드" 이자 "base 산출 코드" 다.
      v16 에서 쓴 것과 같은 절차이며 별도 파일로 중복 저장하지 않는다.
        (a) 깨끗한 섹터(compass >= 280 || <= 35)에서 고도별 base 프로파일
        (b) 오로라 없는 고도대(el 12~22)에서 행성 방위 4% 가산 형상 Wp 를 분리
        (c) 차분 = 격자평균 - base(el) - Wp(az)*s(el)
            -> 방위 +-4도 / 고도 +-1도 평활화
            -> 테이퍼 SS((el-23.5)/2) * (1 - SS((el-52)/4))
            -> max(0, ·) 정류
      ★(b) 를 빼두지 않으면 행성 방위 가산이 오로라 추출에 섞여
        행성 주변 하늘이 함께 파괴된다.

    ★차분 편집이 재굽기보다 강한 이유
      texel_v13 = clamp01(texel_v11 - A_v11 + (없음))
      오로라대 밖은 비트 단위로 동일하다. 재굽기로는 얻을 수 없는 보장이다.
      클리핑된 텍셀에서도 성립한다: 관측된 차분을 빼면 base 가 정확히 복원된다.
