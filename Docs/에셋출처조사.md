# 에셋 출처 조사 — 합치기 전

조사일 2026-08-26 · 대상 `IMUNROK` / 브랜치 `feature/case-onggojip`
`Assets/` 총 **4.0 GB** (2,736 에셋)

---

## 0. 한 줄 결론

**큰 팩은 다 에셋스토어에서 왔다 — GUID 문제가 없다.**
문제는 팩이 아니라 **우리가 만든 것 중 `.meta` 가 git 에 안 올라간 130여 개**다.
그 대부분이 **인물 일곱**이고, 팀원이 그 폴더를 *직접 임포트*하면 씬의 사람이 전부 사라진다.

---

## 1. 조사 방법

1. **에셋스토어 캐시**를 읽었다 — `%APPDATA%\Unity\Asset Store-5.x\`
   `.unitypackage` 7 벌(합 10.4 GB)이 게시자 이름으로 갈려 있다.
2. **폴더 이름이 팩 이름과 다를 수 있으므로** 폴더 안의 파일 구조·재질 이름·README 를
   대조해 짝을 지었다. (예: `HwaseongHaenggung` 폴더 ↔ `kcisa - HWASEONG HAENGGUNG` 팩)
3. **실제로 쓰는지**는 이름이 아니라 **GUID 를 좇아** 판정했다.
   씬·프리팹·재질을 뿌리(241 개)로 삼고 `guid:` 참조를 닫힐 때까지 따라가
   닿은 에셋 **1,351 개**를 모았다. 닿지 않은 것은 안 쓰는 것이다.
4. **git 추적 여부**는 `git ls-files -z` 로 읽었다.
   (`git ls-files` 를 그냥 읽으면 한글 경로가 8진 이스케이프로 나와 **전부 미추적으로
   잘못 잡힌다**. 이 조사에서 한 번 그렇게 헛짚었다.)

## 3. 위험도 — GUID 가 팀원과 같은가

판정 기준은 둘이다.

* **스토어에서 온 것**은 팩 안에 GUID 가 박혀 있다 → 각자 임포트해도 **같다**. 안전.
* 스토어가 아닌 것은 **`.meta` 가 git 에 있어야만** 같다.
  `.meta` 가 없으면 유니티가 임포트할 때 **새 GUID 를 지어낸다** → 씬의 참조가 통째로 끊긴다.

## 4. 진짜로 깨질 것 — 씬이 가리키는데 `.meta` 가 git 에 없는 것

우리 씬에서 좇아 닿은 것 가운데, 스토어도 아니고 `.meta` 도 없는 것이 **149 개**다.

### ① 인물 — 130 개 🔴 가장 위험

```
Assets/_Project/Onggojip/Art/Characters/
  늙은하인 · 마름 · 마을사람 · 복동 · 서리 · 아내 · 옹덕구
```

`.gitignore` 가 **폴더를 통으로** 막고 있다:

```
/Assets/_Project/Onggojip/Art/Characters/
```

그래서 `.fbx`·`.png` 뿐 아니라 **`.mat`·`.controller` 까지 같이 빠졌다.
이 둘은 아트가 아니라 **배선**이다 — 어느 클립을 어느 상태에서 트는지가 거기 적혀 있다.
같은 함정을 `Art/Tools` 에서 이미 한 번 밟고 확장자별 규칙으로 고쳤는데
(`.gitignore` 에 그 내력이 적혀 있다), **인물 쪽은 안 고쳐졌다.**

> **팀원이 인물 폴더를 공유폴더에서 `.meta` 까지 통째로 받으면 문제없다.**
> 각자 fbx 만 받아 임포트하면 **일곱 사람이 전부 사라진다.**

### ② 소품 — `Onggojip/Art/Props` 🔴

같은 꼴이다(`/Assets/_Project/Onggojip/Art/Props/` 폴더째 차단, `.meta` 0/107).

### ③ 관아 세트 메시 — 13 개 🟠

```
_Common/Sets/Gwana/Donheon/Meshes/
  SM_동헌지붕 · 대장책 · 문서궤 · 서가_동_0·1 · 서가_뒤_0~4 · …
```

`*.asset` 확장자 규칙이 막고 있어 `.meta` 도 같이 빠졌다.
이건 **생성물**(메시 줄이기 결과)이라 다시 구울 수는 있으나, 다시 구우면 GUID 가 갈린다.

### ④ 도구 아이콘 — 4 개 🟠

```
_Project/Art/UI/Icons/T_Icon_journal · lantern · magnify · map .png
```

`.gitignore` 가 `Art/UI` 를 한 겹 열어 `*.meta` 를 살려 두었는데,
**`Icons/` 한 겹 더 아래는 그 예외가 안 미친다.** 도구벨트 아이콘 넷이 여기 있다.

### ⑤ 그 밖 2 개

* `Assets/WitConfiguration.asset` — Wit.ai(말하기) 설정. **서버 토큰이 들어가므로 일부러
  안 올린 것일 수 있다.** 팀원은 각자 만들어야 한다(`[Meta ▸ Voice SDK ▸ Get Started]`).
* `_Common/Audio/SFX/문_두드림_하나.wav.meta` — 아직 커밋 안 한 새 파일.

## 6. 합치기 전에 해야 할 것 — 짧은 차례

정리(㉠㉡)보다 **이쪽이 먼저다.** 지우는 것은 되돌릴 수 있지만 GUID 는 못 되돌린다.

1. **인물·소품 폴더의 `.meta` 를 커밋한다.**
   `Art/Tools` 에 이미 쓰인 방식 그대로, 폴더를 통으로 막지 말고 **무거운 확장자만** 막는다.

   ```gitignore
   /Assets/_Project/Onggojip/Art/Characters/**/*.fbx
   /Assets/_Project/Onggojip/Art/Characters/**/*.png
   …  (.mat · .controller · .meta 는 커밋)
   ```

2. **`Art/UI/Icons` 예외를 한 겹 더 연다** — 아이콘 넷의 `.meta` 를 살린다.
3. **`_Common/Sets/Gwana/**/*.asset` 의 `.meta`** 를 살릴지 정한다
   (다시 구울 수 있으나 GUID 가 갈린다).
4. **팀원에게 이르는 말 한 줄**:
   공유폴더에서 받은 아트는 **`.meta` 까지 통째로** 제자리에 넣을 것.
   유니티에서 임포트(드래그) 하지 말 것 — 그 순간 GUID 가 새로 지어진다.
5. `WitConfiguration.asset` 은 **각자 만든다**(토큰이 들어 있다).
