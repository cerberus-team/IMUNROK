# 에셋을 어디에 두나

한 줄 규칙: **사건 것은 사건 폴더, 나머지는 `_Project` 바로 밑.**

```
Assets/_Project/
  Art/            공통 아트
    Fonts/          글씨
    Materials/      재질 — 공통 재질은 전부 여기 하나뿐이다
    Meshes/         손으로 만든 메시
    Props/          공통 소품 모델 + Textures/
    Shaders/
    Tools/          수첩·지도·등불·돋보기·유척·마패
    UI/             아이콘
  Audio/          → 지금은 _Common/Audio 에 있다(§ 아직 못 옮긴 것)
  Data/           ScriptableObject
  Prefabs/        공통 프리팹(두루마리 등)
  Scenes/Core/    IntroScene · HubScene · EndingScene
  Scripts/        전부 여기. 사건 폴더에 스크립트를 두지 않는다
  Settings/

  Onggojip/       제1사건 — Art/ Prefabs/ Scenes/ Data/
  Seocheon/       제2사건
  Gyeonu/         제3사건
```

## 한 번 어긴 자리

- **재질이 세 군데에 있었다** — `Art/Materials`(6) · `_Common/Materials`(12) ·
  `_Common/Prefabs`(8, 프리팹 폴더 안에 재질이 섞여 있었다).
  2026-08-27 에 `Art/Materials` 한 곳으로 합쳤다(21개, `AssetDatabase.MoveAsset`
  이라 GUID 는 그대로다 — 일곱 씬 전부 끊긴 참조 0).
- **`Art` 가 두 곳이었다** — `_Project/Art` 와 `_Project/_Common/Art`.
  후자는 폰트 말고는 비어 있었다.

## 아직 못 옮긴 것 — 왜

`_Common/Art/Fonts` · `_Common/Audio` · `_Common/Sets` 는 **일부러 두었다.**

`.gitignore` 가 이 경로들에 **한 줄 한 줄 매여** 있다. 아트는 git 이 아니라
공유폴더로 도는데, 그러면서도 `.meta` · `.mat` · `.controller` 는 **배선이라
반드시 커밋해야** 한다 — `.meta` 가 빠지면 팀원이 모델을 임포트하는 순간
GUID 를 새로 지어내고, 씬이 가리키던 것이 통째로 사라진다.

그 그물이 지금 이렇게 짜여 있다:

```
/Assets/_Project/_Common/Art/*          ← 폴더째 막고
!/Assets/_Project/_Common/Art/Fonts/    ← 폰트 폴더만 한 번 열고
/Assets/_Project/_Common/Art/Fonts/*    ← 안에서 다시 막고
!/…/Fonts/*.meta                        ← .meta 만 되살린다
```

경로를 옮기면 이 넉 줄이 한꺼번에 헛돈다. 게다가 **팀원 안내문과 각자의
공유폴더 배치**도 같은 경로를 가리키고 있어서, 셋을 함께 고치지 않으면
다음 사람이 받았을 때 자리가 어긋난다.

옮기려면 **한 번에, 일부러** 해야 한다 — `.gitignore` · 팀원 안내문 ·
공유폴더를 같은 커밋에서. 지나가는 정리로 건드릴 자리가 아니다.

## 새 에셋을 들일 때

1. **이 사건에서만 쓰나?** → `<사건>/Art/…`
2. **여러 사건이 쓰나?** → `_Project/Art/…`
3. **에셋스토어 팩인가?** → `Assets/` 밑 제자리에 그대로 둔다.
   옮기면 팀원이 다시 임포트했을 때 GUID 가 어긋난다.
4. 무거운 확장자(`.fbx .glb .png .wav .mp3`)를 넣었으면 `.gitignore` 를 보고,
   **그 폴더가 아니라 확장자로** 막혀 있는지 확인한다. 폴더째 막으면
   `.meta` 까지 같이 빠진다 — 이 프로젝트에서 두 번 밟은 함정이다.
