## 단서

`J`는 1막 잠행에서만, `G`는 2막 관아에서만 얻는다. **굵은 것**은 출도 필수 단서다(`RequiredForReveal`).
번호를 고칠 때는 씬이 실제로 주는 번호와 맞춰야 한다.

### 1막 — 잠행 (J)

| 번호 | 단서 | 얻는 곳 |
|---|---|---|
| J01 | 마을은 甲을 주인으로, 담 밖 사내를 죽은 종 복동이라 부른다 | 마을 사람 · 乙 |
| **J02** | 甲 — 「장부는 스무 해를 내 손으로 적었소」 | 甲 (장부를 만지려 하면 말린다) |
| J03 | 甲이 집안일을 지나치게 잘 안다 | 甲 |
| J04 | 마름의 취중 증언 — 둘이 닮았다 | 마름 |
| J05 | 하인들이 호칭에 머뭇거린다 | 늙은 하인 |
| **J06** | 장부 필적이 한 달 전후로 바뀌고, 맞은편 백지에 미리 쓴 자국 | 사랑방 장부 |
| J07 | 물목 장부 — 최근 한 달치에만 수결이 있다 | 사랑방 문갑 |
| J08 | 차용증 — 이자가 연 10할 갑리 | 사랑방 문갑 |
| J09 | 미회수 수표 — 무장현 박가에게 일백 냥 | 사랑방 |
| J10 | 아궁이 재 — 한여름에 불을 땐 자리, 타다 만 서찰 | 마당 아궁이 |
| **J11** | 보료 밑 별급문기 — 수취인 「오래 부린 종 복동」 | 사랑방 보료 |
| J12 | 호적대장(삼 년 전) — 노 복동이 살아 있다 | 사랑방 |
| **J13** | 호구단자(올해) — 「노 복동 임오년 유월 사망」, 관리 필적이 아니다 | 사랑방 |
| J14 | 甲이 형제를 딱 잘라 부인했다 | 甲 |
| J15 | 문갑 자물쇠가 비틀려 부서졌다 | 사랑방 문갑 |

문갑(J07·J08)은 부서진 자물쇠(J15)를 알아본 사람에게만 열린다.
J08을 놓친 사람을 위해 2막 문서고에 소지(G14)를 두었다.

줄마다 사람 하나와 증좌 하나를 고른다. 조사에서 캐낸 단서만 보기에 뜬다.

### 네 끝

만점 44점, 틀린 줄마다 1점 감점.

| 끝 | 조건 |
|---|---|
| **참** | 진실대로 + 모든 줄 + 30점 이상 |
| **자비** | 정상참작 + 모든 줄 |
| **반** | 핵심 줄의 증좌가 기준에 못 미친다 |
| **헛** | 핵심 줄의 사람이 틀렸거나, 가짜를 그대로 두는 처분을 골랐다 |
