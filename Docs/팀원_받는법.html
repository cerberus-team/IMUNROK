이문록 받는 법

이 프로젝트는 git 에 배선만 들어 있습니다. 무거운 아트는 공유폴더로 옵니다. 그래서 받는 순서와 방법이 결과를 가릅니다 — 잘못 받으면 오류 한 줄 없이 사람이 사라집니다.

유니티 6000.3.19f1 파이프라인 URP · Linear 공유폴더에서 받을 양 1.76 GB 갱신 2026-08-26

차례다섯 걸음

순서가 중요합니다. 아트를 먼저 넣고 git 을 받으면 유니티가 그 사이에 임포트를 시작해 버립니다.

  1. 1

    유니티를 먼저 맞춥니다

    6000.3.19f1 이라야 합니다. 다른 버전에서 열면 재질이 죄 분홍으로 뜹니다. Unity Hub 에서 이 버전을 먼저 깔아 두십시오.

  2. 2

    git 을 받습니다 — 유니티는 아직 열지 않습니다

    git clone 또는 git pull. 씬·프리팹·재질·애니메이터· .meta 가 다 여기 들어 있습니다.

  3. 3

    공유폴더의 아트를 폴더째 제자리에 덮어씁니다

    아래 어디에 무엇을 표대로 넣습니다. 폴더를 통째로 끌어다 놓으면 됩니다 — 안에 든 .meta 가 같이 와야 하고, git 에서 받은 .meta 와 겹치면 그냥 덮어쓰십시오. 같은 파일입니다.

  4. 4

    말하기 설정은 각자 만듭니다

    토큰이 들어가는 파일이라 git 에 없습니다. 유니티를 연 뒤 Meta ▸ Voice SDK ▸ Get Started 에서 Built-In Models ▸ Korean 을 고르면 Assets/WitConfiguration.asset 이 생깁니다. 그다음 이문록 ▸ 소리 ▸ 말하기 붙이기 를 한 번 누르십시오.

  5. 5

    이제 유니티를 엽니다

    첫 임포트에 십몇 분 걸립니다. 텍스처 몇 천 장을 굽는 중이니 그대로 두십시오. 끝나면 아래 됐는지 보는 법으로 확인합니다.

금지이 셋만은 하지 마십시오

셋 다 뿌리가 하나입니다 — GUID. 유니티는 파일을 이름이 아니라 .meta 에 적힌 GUID 로 가리킵니다. 그 번호가 갈리는 순간 씬은 아무것도 못 찾습니다. 그런데 오류가 안 납니다. 그냥 조용히 빕니다.

fbx · png 를 유니티 창에 끌어다 놓지 마십시오

끌어다 놓는 순간 유니티가 새 GUID 를 지어냅니다. 씬이 가리키던 번호와 달라지고, 관아 뜰에 서 있던 사람 일곱이 통째로 사라집니다. 아트는 탐색기에서 폴더째 복사해서 넣는 것입니다.

.meta 를 빼고 복사하지 마십시오

탐색기에서 .meta 가 안 보이면 숨김 파일이 꺼져 있는 것입니다. 보기 ▸ 숨긴 항목을 켜고 다시 복사하십시오. GUID 는 그 파일에만 적혀 있습니다.

에셋스토어 팩을 통째로 다시 임포트하지 마십시오

안 쓰는 조각 2.2 GB 를 이미 걷어냈습니다. 통째로 임포트하면 그게 도로 들어옵니다. 공유폴더에 있는 것이 이미 추려 놓은 것입니다.

WitConfiguration.asset 을 커밋하지 마십시오

안에 계정 토큰이 들어 있습니다. .gitignore 로 막아 두었으니 git add -f 로 억지로 올리지만 마십시오.

배치어디에 무엇을

왼쪽이 공유폴더, 오른쪽이 이 프로젝트 안의 자리입니다. 없는 폴더는 만들어서 넣으십시오.

확인됐는지 보는 법

넷 다 맞으면 제대로 받은 것입니다.

  • 씬 일곱을 하나씩 엽니다. 분홍색 물체가 하나도 없어야 합니다. (분홍 = 재질이 없다 = 팩이 안 들어왔다)
  • 관아 씬(Onggojip_Gwana)에서 뜰에 사람 다섯과 대문 앞 서리가 서 있어야 합니다. 비어 있으면 인물 폴더를 잘못 넣은 것입니다.
  • 계층 창에 “The referenced script is missing” 경고가 없어야 합니다.
  • 자막·수첩의 한글이 네모로 안 깨져야 합니다. 깨지면 폰트를 안 넣은 것입니다.

고장이럴 때는

이런 일이까닭이렇게
사람이 한 명도 안 보인다 .meta 없이 넣었거나, 유니티에 끌어다 놓았다 인물 폴더를 지우고 공유폴더에서 다시 통째로 복사
물체가 죄 분홍이다 팩이 없거나 파이프라인이 URP 가 아니다 배치 표대로 넣기 · 유니티 버전 확인
사람이 T 자세로 미끄러진다 애니메이터 컨트롤러가 안 왔다 git pull 을 다시 (컨트롤러는 git 쪽에 있습니다)
한글이 네모다 폰트가 없다 _Common/Art/Fonts/ 를 넣기
심문에서 말이 안 들린다 Wit 설정을 안 만들었다 차례 4 를 다시
헤드셋에서 아무것도 안 눌린다 링크를 재생 뒤에 켰다 그대로 45초 기다리면 붙습니다

왜 이렇게까지 하나

아트를 git 에 올리면 저장소가 몇 GB 가 되고, 텍스처 한 장을 고칠 때마다 그 한 장이 통째로 다시 쌓입니다. 그래서 무거운 것은 공유폴더, 배선은 git 으로 갈라 두었습니다.

그런데 그 둘을 잇는 끈이 .meta 하나입니다. 끈이 끊어져도 유니티는 아무 말도 안 합니다 — 씬은 열리고, 오류는 없고, 그저 사람이 없습니다. 위의 금지 셋은 전부 그 끈을 끊지 않기 위한 것입니다.

막히면 그냥 물어보십시오. 잘못 받은 것을 한참 붙들고 있는 것보다 폴더를 지우고 다시 받는 편이 늘 빠릅니다.
